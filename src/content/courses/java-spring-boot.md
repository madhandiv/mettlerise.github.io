## Course Overview

Master enterprise Java development with Spring Boot, the most popular framework for building production-ready applications. Learn to create scalable microservices and RESTful APIs used by major companies worldwide.

## What You'll Learn

- **Core Java**: OOP concepts, collections, multithreading
- **Spring Framework**: Dependency injection, Spring Core, Spring MVC
- **Spring Boot**: Auto-configuration, starters, and rapid development
- **Database Integration**: Spring Data JPA, Hibernate, MySQL
- **RESTful APIs**: Building and consuming REST services
- **Microservices**: Service discovery, API Gateway, circuit breakers
- **Security**: Spring Security, JWT authentication
- **Testing**: JUnit, Mockito, integration testing

## Course Modules

### Module 1: Core Java Fundamentals
- Java syntax and OOP principles
- Collections framework
- Exception handling
- Multithreading and concurrency

### Module 2: Spring Framework Basics
- Inversion of Control (IoC)
- Dependency Injection
- Spring Bean lifecycle
- Aspect-Oriented Programming

### Module 3: Spring Boot Development
- Spring Boot architecture
- Auto-configuration
- Building web applications
- Application properties and profiles

### Module 4: Database & JPA
- JDBC vs JPA
- Hibernate ORM
- Spring Data JPA repositories
- Query methods and custom queries

### Module 5: RESTful Web Services
- REST principles and design
- Creating REST endpoints
- Request/response handling
- Exception handling and validation

### Module 6: Microservices Architecture
- Microservices concepts
- Spring Cloud components
- Service discovery with Eureka
- API Gateway and load balancing

### Module 7: Security & Deployment
- Spring Security fundamentals
- JWT token-based authentication
- Dockerizing Spring Boot apps
- Deployment to cloud platforms

### Module 8: Capstone Project
- Build an enterprise application
- Implement microservices
- Complete testing and deployment
